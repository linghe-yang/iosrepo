From the Custom Offsets in Settings you can review and modify the custom offsets that can be applied on top of the current tuning. This is a rarely used feature.  But if you have reasons for departing from the calculated tuning curve and establishing note-by-note exceptions, then this is the place to do it.   The offsets you enter will be stored in the current tuning file and used any time that tuning file is loaded again. These custom offsets can also be set from the main offset on the main tuning page by tapping on the offset display and following the prompt.

On this page you can also set all 88 custom offsets to zero and force a scroll to the offset for the currently selected note.
