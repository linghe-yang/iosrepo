Editing Inharmonicity Constants

This page shows a list of the inharmonicity measurements that have been made for the current tuning.  If the measurements were make with TuneLab version 3.2 or later, those measurements will be associated with the individual offsets for each partial that were used to calculate the inharmonicity constant.  To see those individual offsets, long-press (tap and hold) any measurement and a table will be shown with those offsets. If you want to delete or modify an inharmonicity measurement for any note then tap on the item and follow the prompt.  Note, however, that if the inharmonicity constant is edited then it will no longer represent the stored individual partial offsets for that note.  For this reason editing inharmonicity constants is discouraged.  It is much better to measure the inharmonicity for that note again and get a fresh set of offsets associated with that measurement.

You can view a graph of all the measured inharmonicity constants as well as the projected inharmonicity for every note based on those measurements by tapping the zoom mode button on the Tuning Curve page, as described in the help file for that page.
