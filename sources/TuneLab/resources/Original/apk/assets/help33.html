You can turn Auto-note Switching on by swiping from the Current Note display all the way to the right.  If Auto-note Switching is already on, swiping to the right will cycle through these mode:

Auto up: TuneLab will switch to a higher note that you play if that note is within 3 semitones of the current note.

Auto down: TuneLab will switch to a lower note that you play if that note is within 3 semitones of the current note.

Auto both: TuneLab will switch to any note that you play if that note is within 3 semitones of the current note.

Auto all: TuneLab will switch to any note that you play (all 88 notes) with no restrictions.

Switch only on Trigger: Checking this box causes the auto note switching code to run only when the volume suddenly goes up, which happens when a note is first played.  If this box is not checked then auto note switching code runs whenever auto note switching is enabled. Read about Triggers here.

If you swipe from the Current Note display to the left this will turn Auto-note Switching off.  The state of Auto-note Switching is always shown on the right side of the screen, just above the Phase Display.
