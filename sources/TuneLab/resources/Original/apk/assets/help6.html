On this page you can select and load an existing tuning file.  You can also navigate to various folders and delete or rename existing tuning files and folders.

If you have created any folders to manage your tuning files, they will appear at the top of the list with the symbol shown here.  Tap on a folder name if you want to navigate to it.  When you have navigated to a folder, and you want to go back up one level, tap on the "<back" button.

 To delete or rename any tuning file or empty folder, tap and hold on the item you want to delete. You cannot delete a folder unless you first delete all the files in that folder.

If the number of tuning files is very large, you can avoid the trouble of scrolling through a very long list by tapping the search button at the top of the screen. This will open up a box where you can type a portion of the file name and the list will be filtered to show only the files with that portion of the name.
