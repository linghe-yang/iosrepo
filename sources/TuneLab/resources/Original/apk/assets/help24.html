Generally, it is easier to just start over from the beginning because the pre-measurement process is so quick.  But if you are interrupted part-way through the pre-measurements, you can tap on the "Resume" button.  This will keep any existing pre-measurements you made before you were interrupted and start measuring from whatever is the Current Note.  On the other hand, the "Start" button will erase any existing pre-measurements and start over in taking pre-measurements.
