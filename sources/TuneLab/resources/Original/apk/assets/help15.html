When taking a sequence of inharmonicity readings for a new tuning it is convenient to let TuneLab switch to the next note in your desired sequence immediately after each note is measured.

On the Edit Measure Sequence page in Settings you can set up which notes you want to be automatically selected for inharmonicity measurement when making a new tuning.  Tap on the spot for any note to toggle between 'M' and '-'.  Notes marked by the 'M' are the ones you want to measure. For example, you could measure C1, C2, C3, C4, and C5.  Note: You do not need to limit yourself to the notes in the Measure Sequence defined this way.  You can always select notes manually, or with auto note switching and measure whichever notes you like.

When a "new tuning" is selected from the Settings menu, TuneLab will switch to the lowest note marked with an 'M'.  It will not automatically start the measurement. You  still have to do that by tapping on the measure button, shown here.  After you Save the first measurement, TuneLab will automatically switch to the next note marked for measuring with an 'M', and so on.  At each note, you only need to tap the measure button just before you play the note for a measurement. As each inharmonicity measurement is made the tuning curve is automatically adjusted to take the revised list of inharmonicity measurements into account.

To further assist in augmenting and controlling the Measure Sequence, you can measure consecutive notes or disable auto measure sequencing entirely as described here. The option to measure consecutive notes can be useful when measuring a group of bass strings that have an irregular inharmonicity pattern.
