Multi-partial Phase Display Option

Normally the Phase Display only shows the tuning of the selected partial for the given note.  To see the tuning of a different partial you would have to change the selected partial. But if you enable the multi-partial display option then the Phase Display shows the tuning of several partials at once.  The purpose of this option is to allow you to take into account several partials at once to set the tuning.

This is what the phase display looks like showing the tuning of partials 2, 3, 4, and 6.  The Phase Display is divided into four bands, each of which acts like a Phase Display for a particular partial.  If the inharmonicity model were perfect, all partials would be in tune at once.  But due to imperfections in the model the individual partials are not in perfect agreement.  This display allows you to view the extent to which those partials do not conform to the model so that you can take that discrepancy into account if you wish and tune for a compromise between those partials.  There is also a mode in which the tuning error in these several partials are combined in an average and displayed as a single Phase Display.

See Multi-partial Mode Setup for information on how to manage this option.

>>>  Note that when the multi-partial mode is enabled, the Settings item labelled "Edit Table of Partials" takes you to the table of multi-partials.  If you want to edit the regular single partial table while in this mode go to Settings and instead of tapping on "Edit Table of Partials", touch and hold (long-press) "Edit Table of Partials".  That will take you to the single partial table regardless of whether the multi-partial mode is enabled.
