By tapping on the interval selection button in the Tuning Curve Adjuster page you can select the bass and treble intervals that are used to draw the Deviation Curve (the lower graph on the Tuning Curve Adjuster page).  Each interval is specified by two numbers that give the coincident partials of that interval.  For example, the 4:2 octave is so-named because it is the comparison of the 4th partial of the lower note with the 2nd partial of the upper note.  For whatever interval you select, the Deviation Curve shows how that interval will turn out in the current tuning.  The graph shows how far off that interval will be from pure.

In 3-part tuning this setting has no effect on the tuning curve.  But in old 2-part tuning (pre-2020), the selection of these intervals also controls the tuning curve itself.

Tap on the "Make Default" button if you would like the current interval selections to be used for any new tuning file that is created by the "New tuning" item in Settings.
