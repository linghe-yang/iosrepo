If you would like to use a temperament that is not already in your device then you can add it using the "new" button in the Unequal Temperaments list.  You only have to enter a name for the temperament in the box at the top and then enter the 12 offsets that define the temperament. Finally, tap on the "Save" button at the bottom of the list.  Then the temperament will be available for you to apply to any tuning. It will also select this temperament for the current tuning.
