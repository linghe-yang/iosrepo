Normally when the partial is changed, either manually by swiping through the Spectrum Display, or automatically by Auto Partial Selection, the partial change for the current note is temporary. The next time that note is selected, the partial for that note will go back to what it was in the table of partials for that tuning.  But when the Persistent Partials switch is turned on (yes) then any changes made to the partial for any given note is stored in the table of partials for the current tuning. That way the changed partial will be used every time that note is selected. Thus, when the Persistent Partials switch is turned on, changes made to the current partial will be stored in the tuning file for the current tuning.
