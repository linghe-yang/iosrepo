TuneLab Licensing

TuneLab is licensed based on verification of your license number online.  After purchasing the license you are assigned a license number that you can enter on the Licensing page in TuneLab Settings.   You can purchase a license at our website at

www.tunelab-world.com/cart

If you have already purchased TuneLab for Android and need a license number you can request a permanent license number by e-mail at sales@tunelab-world.com. To activate the license you must do an initial online verification, which you can do immediately after entering the number, or later on.  After the initial verification, TuneLab will operate in paid mode.

If you have not yet verified the license number online you can verify it by going to the Licensing page and tapping the "Other Options" button.  This license can be moved easily to a different Android device whenever you like.  Just enter the same license number in the new device in the new device and start using it.  When you license a new device you should stop using TuneLab on the old device. The "Other Options" button lets you erase the license number from an old device when you want to change to a new device.  The license does not allow using the same license number on two different devices simultaneously.

In the event that the device running TuneLab is not capable of Internet access, there is an alternative Legacy form of licensing uses a license number that only works for the one device for which it was computed.  To use this form of licensing, tap the "Other Options" button and follow the instructions to use send us the Legacy Device ID.  Then you will receive a Legacy license number that will work for that device only.  Also, if the device is ever factory reset, the Legacy Device ID will change, so you will need to send us the new Legacy Device ID so we can send you a new Legacy license number.
