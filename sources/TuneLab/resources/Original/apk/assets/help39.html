Inharmonicity Results

This screen shows the results of an inharmonicity measurement so that you can decide whether to save the result in the tuning file or discard it.  To help you decide, the results show the offset for each partial detected as well as the normalized amplitude (strength) of each partial.  The button labeled "Save" will save the inharmonicity results and exit.  The button labeled "Save+" is shown if you have already saved a previous result for the same note.  Tapping "Save+" will average the current measurement with the previous measurements, but it is not usually necessary since measurements are generally quite repeatable.  The "Discard" button will just exit without saving the current measurement into the tuning.  The "Delete Prior" button is only shown if a prior measurement exists for the same note.  Tapping that button will delete the prior measurement so that you can save the current measurement without averaging it with any prior measurement.

For more detailed diagnostic information on the current reading, long press (touch and hold) the field that says "For: <note name>".  Doing so will present a menu of alternate quantities to display in place of the "Amp" field in the 3rd column.  The choices are "Amplitude" (the default), "Signal/noise ratio", "Width (of the peak) in cents", and "Failure reason".

Amplitude is the normal default strength of the given partial where the strongest partial is assigned to 100.0.

Signal/noise ratio is the ratio of the peak amplitude of the given partial as compared to the average amplitude of the noise within +/- 50 cents of the partial peak.

Failure reason is the reason why a partial was not included in the inharmonicity calculation.  The reasons ranked by priority are:

  • "NoData" if frequency of the partial is either too low or too high to be considered.  In the low bass this excludes partials 1-3.  In the high treble it excludes all but partials 1 and 2.
  • "LoAmp" if the amplitude is so low as to make the measurement of the offset for that partial unreliable.
  • "S/N" if the signal to noise ratio in the region around this partial is too low to rely on the results.
  • "Width" if the peak in the frequency spectrum is too wide, indicating this partial had several peaks very close together.  This usually means the tone was unstable, such as from false beats.

This diagnostic data is not saved for the long term.  But it is available until the app is restarted or until another inharmonicity measurement is made.  To see this diagnostic information after this screen has been dismissed, go Edit Inharmoniticy Constants and tap on the Help button to view the most recent measurement.
