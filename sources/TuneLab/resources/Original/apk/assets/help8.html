A major pitch raise (or pitch lowering) starts out by pre-measuring the pitch of the piano. Using over-pull involves taking pre-measurements and then tuning with over-pull calculations in effect. Therefore, the over-pull settings page is divided into things that relate to pre-measurements and things that relate to the actual tuning. If you do not see all the items on the screen, note that the screen is scrollable. Some of the items at the bottom may not be visible without scrolling.

Tap on the "Start" button to begin.  In this mode you will see "Over-pull pre-measuring" in a yellow box.  Another yellow box shows what note you should play for pre-measurement.  Play each note once.  If you cannot play certain notes (because they are missing or non-functional), then skip them by manually switching to a new note. Before you play each note, make sure TuneLab has switched to that note before you play it.  Playing the note should trigger the measurement. The purpose of this step is for the software to learn how flat (or sharp) the piano is so that TuneLab can figure an appropriate over-pull amount.  After making pre-measurements, you can review and delete some measurements.  TuneLab can work with an incomplete set of measurements, so don't worry if a few notes don't get measured.  The important thing is to make sure that TuneLab assigns each measurement to the correct note, and that you don't get out of sync with TuneLab as these pre-measurements are being made.  If you interrupt pre-measuring, you can resume at any note by tapping on the "Resume" button on the over-pull settings page.  And you can delete incorrect measurements using the Edit pre-measurements button.

Tell TuneLab where the bass bridge and wound strings breaks are by tapping on the adjustment button shown here next to "Bass bridge goes up to .. and Wound Strings go up to..". The bass bridge break is used in the over-pull calculations, and the wound strings break is used to decide which safety limits to use.   You can adjust these safety limits by tapping on the adjustment button next to those limits. You can optionally specify the location of the treble struts. If they are specified they will be used in the over-pull calculations to reduce the over-pull just before the struts, which can improve over-pull accuracy.

If you don't want to pre-measure all 88 notes, you can configure the pre-measurement to choose only white notes, or only notes from a C-major arpeggio.  Tap on the adjustment button next to the description of what notes are to be measured.

After the pre-measurements have been made, you begin over-pull tuning.  In this mode, there is a display of the over-pull offset next to the current note display. If you tap in that display you will instantly see the list of pre-measurements.  To exit from over-pull tuning mode, tap on the red stop button that appears on the main tuning page during over-pull mode.

The Over-pull factor is a multiplier that is applied to the calculation of the over-pull offset. A factor of 1.00 means no change. You can change the over-pull factor to a number larger or smaller than 1.00 to modify this calculation as you see fit.
