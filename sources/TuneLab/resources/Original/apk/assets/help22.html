Tapping on the "Begin using over-pull tuning" button will use whatever pre-measurements have been made and enable over-pull mode. In this mode an over-pull offset will be displayed next to the current note. This offset is meant to counteract the current overall pitch error of the piano as represented by the pre-measurements. Normally over-pull tuning mode is entered automatically at the end of the pre-measurements. But this button allows you to go directly to over-pull tuning mode any time there are any pre-measurements at all. This button will not be visible if there are no pre-measurements at all.
