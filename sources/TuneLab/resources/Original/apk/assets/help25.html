When you select an unequal temperament, you can then choose to normalize it and/or transpose it. Normally you would do neither and just tap on the Done button.

There are two different normalizations you can choose. One is "Normalize for A=0". This will shift the entire temperament (all 12 offsets), if necessary, so that the offset for A is zero. (All the temperaments supplied with TuneLab are already normalized to make A=0, so this option is normally not needed.)

The second normalization option is "Normalize for Avg.=0". This will shift the entire temperament so that the average of all 12 offsets is zero. This is useful to prevent an overall shift in the average pitch of the piano, which would make the piano harder to tune. If neither of the normalizing options is switched on, then any selected temperament would be used "as is".

You can also choose to transpose a temperament. For example, if you choose to transpose by rotating C to F, then the offset that would normally be applied to C is instead applied to F. All the other offsets are similarly rotated. The consequence of transposing a temperament is that some other key signature will take on the characteristics that would have been heard in the key of C.
