Table of Partials

The Edit Table of Partials page in Settings allows you to see and change the partial selections for all the notes up to B6.  Tap on a partial that you would like to change and then tap the "+" or "-" button to raise or lower the partial.  Tap the "dup" button to duplicate the partial selection for the next higher note. (This is a quick way to change the partial for many notes at once.)  Tap on "store as default" if you would like the current selection to be stored as the default for all new tunings that are created with the "New tuning" selection. Otherwise, the partial selection you make here will apply only the currently-loaded tuning file.

This table is for single partial mode and for the Spectrum Display.  To use multi-partial mode in the Phase Display, swipe down from the Phase Display into the Spectrum Display on the main tuning page.  When you select multi-partial mode and then go the "Edit Partials" from Settings, you will be able to view and edit which multiple partials are used for each note in that mode as described here.
