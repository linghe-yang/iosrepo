What's New in this Version (3.2):

  1. An option has been added for a multi-partial Phase Display.  Up to four different partials can be shown in separate bands of moving boxes.  The option is enabled swiping from the Phase Display down into the Spectrum display.  See the help file for the new screen that replaces the single partial table display.  You can switch back to the single partial mode using the same swiping from the Phase Display down into the Spectrum Display.
  2. The behavior of sequencing notes to measure for inharmonicity has changed.  Previously the only sequencing was the one defined by the Auto Measure Sequence table that by default calls for C1, C2, C3, C4, C5.  With this version there is also the option to measure every note in the bass to accommodate bass strings with an irregular inharmonicity pattern.   See the complete description of the new Auto Measure Sequencing here.
  3. Three more long-press options have been added to the buttons on the main tuning screen.  A long-press of the tuning curve button will take you directly to the 3-part tuning setup page.  A long-press of the measure will enable the control of the Auto Measure Sequencing options described above.  A long-press of the Speaker button will present a menu to make the tone generation produce all the partials together instead of generating a sine wave of the current partial.
  4. If you are adjusting the offset by swiping through the Phase Display the adjustment mode will terminate immediately whenever you leave the main tuning screen or open the offset menu.  Previously the only way to disable the offset adjustment mode was to wait for the 45-second time-out.
  5. Inharmonicity measurements are now more accurate by detecting and measuring more weaker partials.  Also the model for how inharmonicity offsets depend on the partial has been revised based on more recent research.  The old model will continue to be used when reading tuning file made before this version of TuneLab, but going forward, all newly-created tuning files will utilize the new model.
  6. An option has been added to display the graph of inharmonicity for all 88 notes.  The graph shows actual measured values in black and the projected values for the other notes in red so that you can see how the measurements are projected across the scale.  See the help file for the Tuning Curve page for details.
  7. After an inharmonicity measurement, on the results screen additional diagnostic information is available on each of the partials measured.  Long-press the field that says "For: <notename>" to see the options.
