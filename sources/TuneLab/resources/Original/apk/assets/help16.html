You can select which set of notes you want to pre-measure before starting an over-pull tuning. The set of notes you pick will be switched to in sequence as you play them.

If you select Every note, then you will get the most complete set of pre-measurements possible, but it will take about two minutes to sequence through all 88 notes.

If you select Every white note, then you will get a fairly complete set of measurements. It will take about one minute to sequence through these 52 white notes.

If you select Notes in C-major arpeggio, then you will get the fastest set of measurements (about half a minute to measure these 22 C-E-G notes).

If the piano is fairly uniform in pitch, then a pre-measurement of just 22 or 52 notes is as good as all 88. If the tuning is very irregular, (as in a new stringing job) then it may be better to pre-measure all 88 notes.
