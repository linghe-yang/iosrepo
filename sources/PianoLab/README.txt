PianoLab 0.1.0 beta 1 — iOS 16 越狱独立钢琴调律应用

本地构建日期：2026-11-03
本版已有可安装的桌面应用、C++ 声音引擎和实际功能入口；没有运行时授权步骤。
安装包已编译、签名并完成本地结构/数值检查，尚未在真实 iPhone / iPad 安装验收。
因此版本标记为 beta，不能把它视为已完成 TuneLab 全功能等价和真琴精度验收的正式版。

选择安装包

普通 Dopamine / Rootless：
  com.linghe.pianolab_0.1.0~beta1_iphoneos-arm64.deb
  安装目录 /var/jb/Applications/PianoLab.app。
传统 Rootful：
  com.linghe.pianolab.rootful_0.1.0~beta1_iphoneos-arm.deb
  安装目录 /Applications/PianoLab.app。
两个包互斥，同一设备只安装符合越狱环境的一种。
目标系统为 iOS / iPadOS 16，ARM64；支持 iPhone、iPad 和横竖屏。
不包含 RootHide 专用包，不向 SpringBoard 或其他应用注入插件。

安装与开始使用

1. 在 Sileo / Zebra 或设备安装工具打开对应 DEB。安装脚本通过 uicache 注册桌面图标。
2. 打开 PianoLab，点“开始监听”，允许麦克风权限。
3. “琴型与文件”可以载入 7 个内置琴型，也可以新建自己的钢琴。
4. 新琴建议先选 C1—C7 等音，隔离同音弦后点“测量非谐性”，再击键并等待结果。
   测量以幅度门槛启动，采集约 0.74—2.97 秒；无效结果会提示重试。
   重复测量同一键会平均，诊断可查看各泛音是否有效、失败码、幅度和 SNR。
5. 调律时选择对应音和泛音，看音分偏差接近 0。低音建议 6 泛音、中音 3、高音 1。
   音分为负表示低于目标，为正表示高于目标。移动条由估计频差驱动。
6. 点“参考音”播放/关闭当前目标正弦音；开始测量非谐性会关闭参考音。
7. 曲线、实测点、自定义偏移、采样校准等自动写入当前琴型；“另存琴型”建立独立副本。
   新建或切换琴型前自动备份当前琴型，可从“打开已存琴型”找回。
8. 切入后台会停止录音；音频中断或设备路由改变后，回到应用重新点开始。

已有功能

麦克风采集、实际输入采样率显示、44.1/48/96 kHz 等输入转到 22050 Hz 处理。
实时目标附近音高分析、音分显示、频谱、手动/自动选音、1—16 泛音选择。
多泛音模式分析所选泛音及最多 3 个后续泛音，合并合格结果的中位值。
完整独立非谐性声音测量、88 键 IH 插值、三段式拉伸、16 种音程组合。
新旧 Beta 模型、旧版固定参数曲线、旧版自动拟合、旧版低音分段。
A4 非标准基准、逐音自定义偏移、21 个内置历史律制、手动及外部参考音采样校准。
过拉预测量、琴桥/缠弦/高音支撑设置、补偿系数、补偿上限及限幅提示。
琴型自动保存/另存/读取、JSON 和 .tun 导入导出、备注、泛音诊断导出。
练习用参考建立、逐音偏差记录和 CSV 对比报告。

预测量与过拉

先关闭过拉补偿，逐音弹奏并等待稳定读数，点“记录当前音的预测量”。
再设置琴桥、缠弦分界、高音支撑和补偿系数，开启过拉补偿。
未预测量的键使用同琴桥侧邻音插值；正向上限默认缠弦 20、裸弦 30 音分。
开启后目标频率包含补偿量；预测量列表显示补偿及是否达到上限。
程序仅计算音高目标，实际操作和钢琴状态仍由调律师判断。

与原 Android 应用的行为差异

非谐性、IH 插值、三段曲线、过拉及旧版拟合有原库基准对照。
实时选音、实时音高估计、击键启动和多泛音合并使用本地独立实现，尚未证明与原程序行为逐项等价。
移动条是根据频率差生成的视觉反馈，没有复刻原程序的全部相位解调/锁定模式。
练习对比入口尚未包含正式 PTG 考试评分、自动失谐和完整考试状态机。
云端文件通过系统文件选择器/分享界面使用，不包含原 Dropbox OAuth 登录。
.tun 导入支持本版使用的主要模型字段；原始文本保存在 JSON 的 originalTun 字段中。
导出会按当前曲线重算行值，不保证未知字段及旧文件中的历史保存音分原样往返。
已知 4 行旧文件保存音分与原库重算不同的现象仍保留在研究记录中。
没有网络时间校准；当前可手动校准或用可靠的外部参考音校准。
没有导入 Android 用户设置或授权数据；不用原 .so、DEX 或模拟器作为运行时组件。

数值检查

11 段原保存 WAV：H 最大差异 0；132 个泛音的有效状态及失败码一致。
190 组模型配置：包含 IH 插值的泛音拉伸最大差异 0.001953125 音分。
1,056 音过拉：与原 DEX 指令输出一致。
32 组旧版自动拟合/低音分段：最大曲线差异约 0.0000171661 音分。
12 组实时音高正弦测试：最大音分差异小于 0.02；噪声输入拒绝。
44.1/48/96 kHz 重采样：分块方式不影响输出；合成 440 Hz 频率检查通过。
以上为测试集的数值差异，不是真实钢琴、iPhone 拾音或任意输入的误差保证。

构建与复现

在 Linux / WSL 中运行：
  python3 tests/validate_core.py
  bash build.sh
使用已有的 Clang 23、Apple ld64、ldid、iPhoneOS 16.5 SDK。
build.sh 默认从工作区 shadebar/tools 读取工具；也可设置 PIANOLAB_TOOLROOT 指向等价工具目录。
然后在 Python 3 中运行：
  python package.py
  python tests/verify_packages.py
在 iosrepo 根目录运行：
  python tools/update_repo.py
  python tools/update_repo.py --check
依赖的 SDK 和工具安装包不随源发布；源码、测试向量、检查报告随源保存。

真机验收

安装后先确认图标可见、应用可启动、麦克风权限可申请、输入采样率非零。
用可靠 440 Hz 外部参考检查稳定读数、正负方向和采样校准。
分别在低中高音完成非谐性测量，查看无效泛音原因及重复测量的平均结果。
测试导入内置琴型、另存、退出重开、文件导出再导入、21 个历史律制选择。
验证过拉关闭/开启的目标变化，以及预测量跨琴桥的插值行为。
测试拒绝权限、耳机拔插、电话中断、后台/前台、横竖屏和 iPad 弹窗。
遇到问题从“琴型与文件 → 导出诊断”导出自身状态；崩溃还需设备系统崩溃日志定位。
