Multi-Partial Settings

On this page you can examine and modify the settings used in multi-partial mode. The first of these settings is the "combined-separate" switch. When this switch is in the "separate" position the multiple partials for a note are displayed in separate bands within the Phase Display. When set in the "combined" position, the indication from the selected partials will be averaged and displayed as a single band of moving blocks, similar to the single partial mode, but the background of the Phase Display will still indicate which partials were averaged for that note.  When the partials are averaged the pitch error from each one is weighted according to the strength of that partial.  Stronger partials are weighted more than weaker partials.

Next there is the selection of the highest note to be displayed in multi-partial mode.  For notes higher than this the note is displayed in single partial mode, regardless of what is listed in the multi-partial table for those notes.
