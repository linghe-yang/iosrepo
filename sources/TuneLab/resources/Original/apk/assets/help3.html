Spectrum zoom lets you select from six different zoom settings for the Spectrum Display. You can also do that with a two-fingered pinch-zoom on the main screen.

Auto note switching lets you turn auto note switching on or off and configure the kind of auto note switching desired (up, down, both directions, all notes). Auto note switching may also be turned on and off from the main tuning page by swiping from the current note display.

Over-pull (pitch-raise or pitch-lowering) manages the process of pre-measuring the tuning of a piano and then setting modified tuning targets to compensate for the overall pitch change that is required.  Use only for major pitch changes.

Non-equal temperaments lets you choose or cancel an unequal (or "historical") temperament to be applied to the current tuning. It also allows you to create a new non-equal temperament by entering the 12 offsets that define the temperament.

Edit IH Constants lets you review and delete any inharmonicity measurements that have been made for the current tuning.

Edit Measure Sequence lets you specify which notes you want to have measured when starting a new tuning.  These notes will be automatically selected for you as you make the measurements.

Edit table of partials lets you examine and edit either the Table of Partials that specifies the partial to be used for each note, or the Multi-Partial Table that specifies the combination of partials are displayed in the Phase Display when the Phase Display is in Multi-Partial Mode.  Which table you see depends on whether or not the multi-partial mode is currently enabled.  Note that regardless of the partial mode for the Phase Display, the Spectrum Display always displays the partial specified in the normal table of partials.  To edit regular single-partial table if the multi-partial mode is selected you can either (1) temporarily switch the Phase Display back to single partial mode as described in the gestures for the main tuning page. Or (2) you can touch and hold (long-press) this item and that will take you to the single-partial table regardless of whether multi-partial mode is enabled.

Auto partial selection configures the option of automatically choosing which partial to use for tuning, normally only for notes in the bass.

Persistent partials is a switch that determines whether the manual changes you make to the partial selection are to be stored in the current tuning file, or whether those changes should be considered just temporary.

Custom offsets lets you manage any custom offsets that you want to apply for specific notes. Custom offsets are normally not used, except to capture and store an existing tuning in the tuning exam mode.

Do a calibration manages the process of calibrating your device for precise tuning.  Normally you only need to do this once when TuneLab is first installed.

PTG Tuning Exam manages the process capturing a master tuning, detuning a piano in preparation for the exam, capturing the examinee's tuning, and creating or viewing a scoring report of the comparison between the examinee's and the master tuning.

Licensing manages the process of getting a license to convert the free-trial mode to the paid mode for this software.

Wide Spectrum Traces is a switch that causes the Spectrum Display to be drawn with thicker traces for improved visibility. Thicker traces also cause a slight reduction in resolution.

Phase display speed is a setting that adjusts the sensitivity of the Phase Display so that the display moves slower or faster than the nominal rate.  A slower Phase Display appears less "jumpy", but is also less sensitive to tuning error.

About this version displays the version number, build date, and the actual calibrated sample rate for your device. You can also reinstall the sample tuning and temperament files from this page and export or import files to and from an external SD memory card.

Dark Mode offers a choice of Dark Mode, Light Mode, or following the system-wide settings of Dark Mode in the overall device.

Spectrum Update Rate is a setting that controls how many updates per second are displayed for the Spectrum Display.
