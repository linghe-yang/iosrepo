This page provides a means to transfer tuning files to and from external memory (such as an SD card or through the USB cable) and this Android device.  (You can also use Dropbox operations from the Files menu on the main tuning page to accomplish the same thing.)

Some Android devices have more than one kind of external memory. There can be true removable memory such as an SD card. And there can be built-in "external" memory. Sometimes both types are present at once.  If there are several such external memories, you can select which one you want to use by tapping the "Change" button.  The path to the selected memory will be shown in the field below the button.  This path is from the perspective of the TuneLab application and is not the same as the path as seen from a desktop file explorer. The following examples show how the path names appear on a Samsung Galaxy A01 Core cell phone with a removable SD card installed.  Your device may be different.

Ext.Mem Paths shown by TuneLab:

/storage/emulated/0/Android/data/com.realtimespecialties.tunelab/files
/storage/3236-6162/Android/data/com.realtimespecialties.tunelab/files

Paths as viewed from USB connection or a File Explorer:

Phone/Android/data/com.realtimespecialties.tunelab/files
Card/Android/data/com.realtimespecialties.tunelab/files

It is very important when accessing the folder from a desktop computer that you only modify the contents of the folder shown associated with TuneLab.  Other folders in External Storage belong to other applications, and should not be modified at all.

Initially the folders shown above do not exist.  You should create the folder you want to use by tapping the Copy to External button.  After the proper folder has been created you can load it with whatever files you want to import into TuneLab.  Then you can use the Load from External button to import the entire contents of the selected folder into TuneLab.  Copying to external storage will automatically create the destination folder if it does not already exist.

The button labelled "Reinstall package files" can be used to reinstall the files that came with TuneLab and were initially installed the first time you ran TuneLab. These would be the sample tuning files, the "Average" tuning file, and the pre-packaged historical temperaments. Reinstalling these files will only refresh the files that came with TuneLab. It will not disturb your custom tuning files or any new temperaments that you may have created.
