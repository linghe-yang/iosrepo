This page allows you to pick an exam report that was created earlier with the "Generate Report" button on the Tuning Exam page. Report files are standard text files with the .TXT extension, and you can copy them out from your device to a desktop computer if you would like to print a report. You can also "Copy to External" on the "About this version" page to copy all tuning files and exam reports to an external SD card or built-in "external" memory, but the Dropbox option is generally easier to use.  When you upload tuning files to Dropbox, the report files are also uploaded.
