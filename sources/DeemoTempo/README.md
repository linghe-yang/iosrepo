# DEEMO Practice Tempo 0.3.0~beta1

适用 DEEMO 5.0.8（1001405，com.rayark.pluto），iPadOS 16 Dopamine Rootless。软件包只包含游戏内插件与加载过滤器。适配的 UnityFramework UUID 为 37b8f14d-ccfd-3358-8c31-cbe88ff67b2a。

在 Sileo 安装后，从多任务界面完全退出 DEEMO，再重新打开。选曲时点左上角的音符倍率按钮，拖动滑条可在 0.10× 到 2.00× 之间连续调节。数值显示到小数点后三位，保存滑条实际值。点“恢复 1×”可回到原速。默认 1.00 倍，下次启动记住选择。正式开曲锁定倍率并收起按钮。与 iGameGod 一起使用时，请将其速度设为 1×，由本插件控制本曲速度。游戏内原有的谱面滚动速度可照常设置。

开曲后，屏幕正上方显示进度条和原曲时间。按住进度条并左右拖动。小白点是播放头，淡色点是手指目标。两点越近移动越慢，拉开距离后逐渐加快。持续按住可让播放头追上目标，松手从白点位置按已选倍率续播。拖动时暂时停住声音，向前拖动会逐帧推进当前游戏谱面，向后拖动会根据目标时间重建可见音符。系统取消手势时回到按下时的位置。

向后拖会按实际判定时刻撤销后续记录，恢复此前的分数、当前与最高连击、Perfect 和 Miss。提前命中的音符按实际命中时刻处理。向前拖会将途中尚未判定且已越过的可打音符各记一次 Miss，同时处理和弦，背景音符不计 Miss。反向拖动再向前时，从本次拖动到达的最早时间重新计算。若实际判定数量和已记录事件不一致，插件停止接受跳转，保留原局状态。

如果设备上的音画有稳定偏差，先用游戏原有的 1× 校准，再在倍率菜单打开“声音延迟微调”。正值使谱面向后对齐，单位为毫秒，范围 −200 到 +200，默认 0。音频效果无法建立时本曲回到 1×，曲后倍率菜单显示原因。

## 工作方式

正式 BGM 的 Unity AudioSource 按所选倍率读取歌曲，在其自己的 FMOD 通道组增加反向音高修正。0.5× 及以上使用 512 帧分析窗口，更低倍率使用 4096 帧窗口和最多四级音高修正，并按级数估算延迟。源音高乘倍率、各级效果器的音高乘数之积等于倍率的倒数。不同倍率和瞬态密集的钢琴段落可能产生不同的音色和延迟。保留原引擎的解码、混音、音量及重试流程。

游戏的主协程按帧推进谱面，并用 BGM 样本位置校正。适配器为此协程换算帧时长、延迟起播、恢复定位和送入校正的样本数。按键音保留原采样音高和力度，仅换算发声等待和时值。暂停期间冻结按键音的等待时钟。整组音符和原有判定逻辑继续使用游戏的歌曲时间，判定窗口以歌曲时间计。练习倍率不会隔离游戏本身的成绩保存行为。

src/Tempo.hpp 包含倍率换算和可替换的音频后端接口。src/Deemo508.hpp 与 src/Adapter.mm 是该版本的适配。更换游戏时要重新识别 BGM、歌曲时钟、按键音和生命周期。包内不含游戏的代码、曲目或谱面。

## 验证与构建

在 Linux/WSL 设置 DEEMO_TOOLROOT 指向本地 ShadeBar 交叉编译工具目录，运行 bash build.sh。构建会运行时钟/回退测试，并生成已签名的 arm64 动态库。在本软件源目录布局下运行 python package.py，再运行仓库的 tools/update_repo.py 及其 --check。安装包为 com.linghe.deemotempo，包架构为 iphoneos-arm64。

可在持有原 IPA 的机器运行 python tests/verify_ipa.py <IPA> 校验应用版本、UUID、46 个入口与 22 处关键调用。python tests/chart_check.py <IPA> [UnityPy依赖目录] 读取原谱面。python tests/render_tone.py [fmod_toolkit依赖目录] 用桌面 FMOD 渲染测试音。桌面 FMOD 和此游戏内的 FMOD 版本不同。

本次检查覆盖 0.100–2.000 范围内 1,901 个倍率的五分钟时钟换算、效果创建失败回退和释放、三首歌共九张谱面及 8,883 个按键音事件。桌面 440 Hz 长音在十二个抽测倍率下的稳定音高为 439.98–440.02 Hz，含 0.10× 与 2.00×。极低倍率会增加处理延迟，钢琴起音的清晰度和真机性能需要试听。尚未在 iPad 上实际安装、录音或测量触击判定。设备验收可从 0.75× 开始，比较曲首与曲尾，暂停恢复后再对拍，随后重试并测试 1.25× 和 1×。如果出现持续漂移，请记录歌曲、难度、倍率、输出设备和发生时刻。

进度功能验证覆盖距离追随、往返与取消、边界和弦、提前命中、晚判 Miss 及去重。尚无本版在 iPad 上实测的画面或成绩记录。建议先在短曲比较前跳的 Miss 数、回到同一时间后分数/连击，以及倍率改变后的重打与续播。
