On the PTG Tuning Exam page in Settings you can:

1. Enable Pre-exam detuning mode or Exam capture mode.

2. Create exam reports or view old exam reports.

3. Force exam mode partials (for a mock tuning exam).

Pre-exam detuning adds in the PTG-specified offsets that are used to prepare the piano for the tuning exam. These offsets alternate between '+' and '-' so that the overall pitch is not affected.

Exam capture mode displays the exam mode offset, rounded to the nearest 0.1 cents in a blue box to the right of the current note display. This mode streamlines the process of moving the main offset into the custom offset for the current note. Just tap once on the "Exam Mode" box and the transfer will take place.

In Tuning Exam Capture mode the partial for each note is forced to be the partial that is specified by the PTG for the tuning exam. Therefore any saved master tuning or examinee's tuning will contain these specified partials. If you want to use a regular tuning file as a master tuning in a mock tuning exam, you can tap on "Force exam partials". This is not needed for tunings created in Exam mode, since they have the correct exam partials already.

When giving an exam, load the master tuning, then enable Pre-exam detuning to prepare the piano. After the examinee tunes the piano, capture the examinee's tuning using Exam capture mode and save the tuning file under a name that identifies the examinee. Then come back to this page and tap on "Generate Report". This will prompt you to select a temperament octave and a master tuning. Then you can view the report, which will be named the same as the examinee's tuning. You can also view old tuning exam reports from this page.  When the list of old reports is displayed you can tap on one of them to display that report.  You can also long-press on the report name and see the following options:

  • Delete this file
  • Rename this file
  • e-mail this file
  • Cancel (showing date and time of the file)

From the main tuning screen, in Tuning Exam mode you can quickly navigate back to the Tuning Exam page without going through Settings by doing a long press on the right status box showing the Exam Mode offset. Tapping once on this field transfers the Exam Mode offset to the custom offset for the current note.
