To save the current tuning so that it can be recalled later, enter a name in the box at the top of the screen and tap on the "Save tuning" button. If you want to save the tuning in some folder then you can first tap on the folder name and then tap on "Save". The current folder name is shown on the second line after the word "in:". You can navigate up and down nested folders before saving the tuning. If you want to create a new folder, then first navigate to where you would like that folder created and then tap on "Make new folder". You will be prompted for the name you would like to give to the new folder.
